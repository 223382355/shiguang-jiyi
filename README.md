# 拍拍故事 · 网页演示版（GitHub Pages）

拍一张照片，说一句今天的故事，选一种风格，浏览器直接生成一张 1080×1820 的纪念海报。海报上有日期、天气、地点、事件梗概和二维码，家人扫码就能留言。

这是一个**纯前端演示版**：只有 HTML / CSS / JS，不需要服务器、不需要安装 Python，上传到 GitHub 后打开网页就能用。部署方式就是你说的 **GitHub → Settings → Pages → Deploy from a branch**。

---

## 一、先了解演示版的三个限制

演示版没有后端，所以有三点和正式版不同，比赛演示时建议主动说明：

1. **AI Key 要自己填在浏览器里**
   点首页右上角的 `AI`，粘贴火山方舟的 API Key 和模型/接入点 ID。Key 只保存在这台手机的浏览器里，但纯前端无法真正隐藏 Key，**只适合演示，不要公开传播填好 Key 的链接**。
   不填也能用：系统会用本地模板生成标题和文案，海报照样能出来。

2. **照片原图不跨设备，但海报图片会同步**
   照片原图只存在生成海报的那台手机里。生成后，整张海报（含照片、日期、二维码）会通过 `ntfy.sh` 同步，家人扫码可以直接看到海报图片，不再只有文字。
   免费附件缓存约 **3 小时**，留言消息缓存约 **12 小时**；图片过期或上传失败时，家人会退回文字版故事卡，留言仍可同步。
   这条通道会经过第三方公共服务器，话题由每张海报的随机密钥生成。**正式版应换成自己的后端**（`snapstory.zip`）；如果 `ntfy.sh` 在你的网络里打不开，海报和留言都会退回本机模式。

3. **海报在浏览器里用 Canvas 绘制**
   显示和保存都正常，但不同手机字体略有差异，排版可能有几个像素的偏移。

除此之外，拍照、相册、语音转文字、EXIF 时间、定位、天气、AI 识别、四种风格、二维码、保存海报都可以正常使用。

### 语音输入说明

「一说」页面新增了「点一下，说话」按钮，使用浏览器自带的语音识别（Web Speech API），说完会自动把中文转成文字，可以再修改。

- 需要 `https://` 打开（GitHub Pages 自带），第一次会请求麦克风权限。
- 点击后按钮会立即变成「正在启动…」，再点一下可以取消或停止；如果 4.5 秒还没启动，会提示改用键盘话筒。
- 开始后会持续听，最多 30 秒；说完再点一下结束，浏览器会把最终结果写进输入框。
- Chrome / Edge 安卓和桌面支持较好；iPhone Safari 部分版本支持；微信内置浏览器、部分国产浏览器可能不支持。
- 浏览器不支持时，按钮会自动变成「用键盘话筒」，点一下会打开输入框，再点手机键盘上的话筒图标说话即可。
- 即使按钮能开始、能结束，也不代表一定能转文字：语音识别依赖浏览器厂商的在线服务，国内网络下可能一直返回空结果。这时页面会提示「没有识别到文字」，并高亮「用键盘话筒」。
- 如果要让所有手机都能在网页里直接录音转文字，需要接讯飞/火山的语音识别接口，并配一个后端服务器。

## 二、部署到 GitHub Pages（约 5 分钟）

### 第 1 步：注册 / 登录 GitHub

打开 <https://github.com>，没有账号就用邮箱注册一个，登录。

### 第 2 步：新建仓库

1. 点右上角 `+` → `New repository`。
2. `Repository name` 填 `snapstory`（也可以叫别的，记下来）。
3. 选择 **Public**（Private 仓库用不了免费的 GitHub Pages）。
4. 不要勾选 `Add a README file`。
5. 点 `Create repository`。

### 第 3 步：把文件传上去

1. 解压 `snapstory-pages.zip`，会得到一个文件夹，里面有 `index.html`、`view.html`、`style.css`、`poster.js`、`app.js`、`view.js`、`sync.js`、`qrcode.js`、`.nojekyll` 和本说明。
2. 在新仓库页面点 `uploading an existing file`。
3. 打开解压后的文件夹，**全选里面的所有文件**，拖进网页上传区。
   - 是拖文件夹**里面**的内容，不要把整个文件夹拖进去。
   - `.nojekyll` 是隐藏文件，看不到也没关系，不影响使用。
4. 点页面下方 `Commit changes`，等上传完成。

### 第 4 步：打开 Pages

1. 在仓库页面点 `Settings`（设置）。
2. 左侧菜单找到 `Pages`。
3. `Build and deployment` 下的 `Source` 选择 **Deploy from a branch**。
4. `Branch` 选择 **main**，右边的目录选择 **/ (root)**，点 `Save`。
5. 等 1～2 分钟，刷新这个页面，顶部会出现：
   `Your site is live at https://你的用户名.github.io/snapstory/`

这个网址就是浏览链接，手机和电脑都能直接打开。

### 第 5 步：确认能打开

- 电脑打开上面的网址，看到「把今天留成一幅画」就成功了。
- 手机打开同一个网址，点「点这里拍照」，会调起手机自带相机。
- 第一次打开如果显示 404，等 1～2 分钟再刷新，GitHub 还在发布。

### 以后改代码怎么更新

在仓库页面点 `Add file` → `Upload files`，把改过的文件重新拖上去，`Commit changes`。GitHub Pages 会自动重新发布，通常 1 分钟内生效。

## 三、手机上怎么用

1. 手机浏览器打开 `https://你的用户名.github.io/snapstory/`。
2. 点右上角 `AI`，填入火山方舟的 Key 和模型/接入点 ID，点保存（不填也能生成，只是文案走本地模板）。
3. 点「点这里拍照」→ 拍一张 → 「下一步」。
4. 点「点一下，说话」说一句，会自动转成文字；也可以直接写，或者「跳过」。
5. 选「文艺 / 喜庆 / 美丽 / 怀旧」其中一种 → 「生成我的海报」。
6. 结果页可以「保存海报」「分享给家人」，也可以打开二维码对应的留言页。
7. 家人扫码后能看到同步过去的整张海报；留言后，老人这边打开着的海报会自动把留言排进去。如果老人已经关掉页面，重新打开留言页会拉取最近 12 小时内的留言。海报图片约 3 小时后过期，过期后家人看到的是文字版故事。

### 火山方舟 Key 在哪里找

1. 打开 <https://console.volcengine.com/ark>，登录并开通「豆包视觉理解」相关模型。
2. 在「在线推理」里创建一个推理接入点，复制接入点 ID（形如 `ep-2024xxxx`）。
3. 在「API Key 管理」里创建并复制 API Key。
4. 回到网页右上角 `AI`：API Key 填第一栏，接入点 ID 填第二栏。

> 纯前端版只接入了火山方舟，因为它的接口允许浏览器直接调用；智谱接口不允许浏览器跨域调用，只在完整后端版里使用。

## 四、常见问题

**打开是 404？**
刚保存 Pages 设置需要等 1～2 分钟；确认 `Source` 是 `Deploy from a branch`，分支是 `main`，目录是 `/ (root)`。

**拍照按钮没反应？**
必须用 `https://` 打开（GitHub Pages 自带 https）。不要直接把 `index.html` 拖进浏览器用 `file://` 打开。

**地点和天气不显示？**
浏览器定位需要用户点「允许」；拒绝定位时会自动改用 IP 粗略定位，地点可能只显示到城市。完全不联网时，日期仍然正常。

**海报上没有 AI 写的文案？**
检查右上角 `AI` 里的 Key 和接入点 ID 是否填对；即使失败也会用本地模板兜底，不会卡住。

**保存不了海报？**
苹果手机可以长按海报图片，选「存储到照片」；安卓一般会直接下载到相册或下载目录。

**换手机扫码看不到海报图片？**
先确认生成海报后网络正常、页面停留过几秒，让海报上传完成。图片通过 `ntfy.sh` 同步，免费附件约 3 小时后过期；过期或上传失败时，家人会看到文字版故事卡，这是演示通道的限制。正式版换后端后没有这个限制。

**子女留言了，老人为什么没看到？**
先确认老人那边的海报页面还开着，或者重新打开一次留言页。留言通过 `ntfy.sh` 同步，需要网络能访问这个域名；如果页面底部提示“实时同步暂不可用”，让子女点「复制留言发给家人」，老人收到后可以手动补进去。正式版请换后端，见 `snapstory.zip`。

**语音按钮能开始、能结束，但没有文字？**
这说明浏览器接受录音了，但它的语音识别服务没有返回结果。常见原因是国内网络访问不了 Chrome 的语音服务，或当前浏览器/输入法不支持中文语音识别。看按钮下面的提示：如果显示「没有识别到文字」或「语音服务连不上」，点高亮的「用键盘话筒」，用手机键盘上的话筒说话即可。要彻底解决需要后端语音识别接口，不能让网页直接依赖浏览器厂商的服务。

## 五、文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 老人端：拍照 → 说一句 → 选风格 → 结果 |
| `view.html` | 家人扫码后的留言页 |
| `style.css` | 老年友好的大按钮、暖色界面 |
| `poster.js` | EXIF、定位天气、AI 调用、Canvas 海报、二维码、本地存储 |
| `app.js` | 首页交互、语音转文字、生成流程、留言实时刷新 |
| `view.js` | 留言页逻辑、跨设备留言同步 |
| `sync.js` | 海报图片和留言的同步通道（ntfy，可替换为后端接口） |
| `qrcode.js` | 二维码生成库（qrcode-generator 1.4.4，MIT） |
| `.nojekyll` | 告诉 GitHub Pages 不要用 Jekyll 处理文件 |
